name: Security Policy
description: |
  Guidelines for reporting security vulnerabilities.

  This project manages personal configuration files (dotfiles) for a single user's desktop environment. It does not handle user data, authentication, or network services beyond what the underlying applications (Hyprland, Neovim, etc.) already do.

  If you find something that seems unsafe — for example, a secret accidentally committed, or a config that exposes your system — please open an issue or contact the repository owner directly.

  Do not paste secrets, passwords, API keys, or other credentials in any issue or pull request.
